🎬 Landing Page de Filmes

📝 Sobre o Projeto

Este projeto é uma Landing Page moderna e responsiva dedicada a apresentar um catálogo de filmes. O foco principal está na experiência do usuário (UX) e em uma interface visualmente atraente (UI), destacando títulos populares e novidades do cinema.

✨ Funcionalidades

Apresentação Visual: Exibição de pôsteres e banners de filmes de alta qualidade (ex: Ghostbusters: Afterlife, Harry Potter).

Design Responsivo: A página se adapta perfeitamente a diferentes tamanhos de tela (desktop, tablet e mobile).

Foco em UX/UI: Interface intuitiva e de fácil navegação para o usuário.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica da página.

CSS3: Estilização, animações e layout responsivo (Flexbox/Grid).

JavaScript: (Opcional) Interatividade e dinamismo na página.

📁 Estrutura do Projeto

A estrutura principal de pastas do projeto está organizada da seguinte forma:

landing_page_filmes/
├── imagens/                 # Pôsteres e banners dos filmes
│   ├── afterlife.jpg
│   ├── harrypotter.jpg
│   └── ...
├── css/                     # Arquivos de estilo
├── js/                      # Arquivos de script
└── index.html               # Página principal


🚀 Como Executar o Projeto

Faça o clone deste repositório:

git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git


Navegue até a pasta do projeto:

cd landing_page_filmes


Abra o arquivo index.html no navegador de sua preferência.
